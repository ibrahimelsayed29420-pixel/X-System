# دمج Deep Agents في عقل X

## المصدر والنسخة

- المصدر: https://github.com/langchain-ai/deepagents
- الالتزام: 6b9e9c9f9088deab6d1c3f12c3c9626605d803a2، حزمة deepagents 0.7.32 تحت MIT.
- نسخة المصدر D:/X-System/runtime/deepagents-source، والبيئة المستقلة D:/X-System/runtime/deepagents-venv.
- حزم التشغيل الفعلية في requirements-deepagents-installed.txt. التحقق من التبعيات نجح.
- نموذج الأدوات المحلي x-qwen-agent:latest مبني على qwen3:4b-instruct، بأوزان مرخصة Apache-2.0 وفق مصدر Qwen. لا استدلال سحابي أو مفاتيح مدفوعة. يعاد استخدام أوزان النموذج المحلي، دون تدريب جديد.

## ما تغير فعليًا

أوامر الهوية والحفظ والحذف المحددة ما زالت مباشرة وواضحة. يختار موجّه محلي حتمي المسار: المحادثة القصيرة تستخدم `x-ibrahim:latest`، والعقارات لها تعليمات تخصصية، والبحث والخطط والتحليل تستخدم `x-qwen-agent:latest` والمهارة المناسبة. لا ينزّل الموجّه نماذج تلقائيًا. العربية والإنجليزية وخلط اللغتين مدعومة في تعليمات الشخصية، ومطابقة لغة المستخدم هي الافتراضية. أوامر remember / learn / show memory / forget أضيفت إلى نظائرها العربية.

الأدوات الموصولة:

1. write_plan: تسجيل خطة عمل قصيرة للطلبات متعددة الخطوات؛ ليست عرضًا للتفكير الداخلي.
2. search_public_web: بحث عام عبر Agent-Reach مع روابط المصادر. ترفض الاستعلامات المحتوية على أنماط بريد/أرقام/مفاتيح حساسة، وتفشل صراحة عند فشل المزود.
3. recall_saved_facts: قراءة الحقائق التي حفظها إبراهيم محليًا.
4. inspect_skill_map: قراءة المهارات وعلاقاتها المسجلة.
5. read_public_page: قراءة صفحة HTTP(S) عامة يطلبها المستخدم عبر Crawl4AI ومتصفح Edge محلي؛ تمنع الروابط المحلية والخاصة وروابط الجلسات.

تُمرر المهارات المحلية المعتمدة فقط إلى Deep Agents تحت `/skills/project/` عبر `StateBackend`. مراجعة المهارة واعتمادها منفصلان عن تنفيذها؛ المهارة لا تضيف أدوات أو صلاحيات، والأدوات الافتراضية غير المسموحة تبقى محجوبة.

الأدوات تعرض نتائج فعلية؛ لا إرسال أو نشر أو أدوات حسابات موصولة. محتوى البحث والصفحات بيانات خارجية غير موثوقة وليس تعليمات. لوحة المتابعة تعرض عنوان الصفحة ورابطها ومقتطفًا قصيرًا من آخر مهمة. أدوات الملفات والأوامر المدمجة في Deep Agents محجوبة عن النموذج، وتوجد قائمة أدوات مسموحة عند التنفيذ أيضًا. التخزين الافتراضي في Deep Agents هو StateBackend داخل حالة المهمة، وليس وصولًا لملفات Windows.

أضيفت مسارات متخصصة داخل عقل X الواحد: `research-specialist` للبحث العام الموثق، و`real-estate-specialist` لتنظيم عروض البيع والإيجار والأراضي والأوف بلان، و`workflow-planner` للخطط القصيرة، إضافة إلى `workflow-orchestrator` عبر Deep Agents للطلبات التحليلية. و`skill-specialist` متاح لقراءة الحقائق المحفوظة وخريطة المهارات فقط. مسودة الإعلان تستخدم قالبًا محليًا يدرج فقط نوع العقار ونوع العرض والإمارة والسعر والمساحة إذا وردت صراحة؛ الباقي حقول للمراجعة، لا مزايا أو توافر مخمّن. المخرجات العقارية تظل للمراجعة البشرية. أدوات الوكلاء محددة، مع حد استدعاء محلي؛ لا shell أو كتابة ملفات أو إرسال أو نشر.

مستودعا MuseBot وHermes Agent موجودان للقراءة فقط تحت `D:\X-System\runtime\musebot-source` و`D:\X-System\runtime\hermes-agent-source`. تم اعتماد نمط المهارات والتوجيه فقط داخل X، لا تشغيل المشروعين أو نسخ خوادمهما إلى مسار التشغيل. MuseBot يحتاج اعتمادًا وقناة مراسلة لإرسال الرسائل؛ Hermes يضيف أدوات تنفيذ واسعة لا نحتاجها في X. لم تُربط قناة ولم تُثبت تبعيات إضافية.

## مسار التنفيذ

طلب إبراهيم ← طابور Windows الخلفي ← استرجاع الذاكرة ← موجّه المسار والنموذج ← محادثة محلية مباشرة أو X/Deep Agents ← وكيل متخصص وأداة مسموحة عند الحاجة ← الرد بلغة الطلب ← حفظ المحادثة والنتيجة.

كل استدعاء أداة وحالة المرحلة يكتب إلى stage.json وevents.jsonl. ملف agent-trace.json يحتوي خطة العمل القصيرة والأدوات والمصادر، دون عرض تفكير النموذج الداخلي. صفحة http://127.0.0.1:18764/ تعرض هذه البيانات، وتتحقق من PID العامل الفعلي حتى أثناء اختبار خارج طابور المحادثة.

## حدود واختبارات

- في الاختبار الحي العربي، اختار النموذج أداة search_public_web ونفذ البحث، وأعاد روابط ajmanre.gov.ae. استغرق الاختبار الكامل 88.22 ثانية؛ الأداء على CPU ما زال محدودًا.
- الاختبار الحي عبر عملية الخلفية رد بالإنجليزي دون بحث غير مطلوب في 20.2 ثانية.
- الاختبار الحي العربي عبر عملية الخلفية رجع ردًا عربيًا دون بحث غير مطلوب في 16.38 ثانية. جودة العامية ما زالت قابلة للتحسين وليست مضمونة بكل رسالة.
- يستخدم قارئ الصفحات `chrome_channel='msedge'` لاختيار Edge المثبت؛ خيار `channel` وحده لم يكن يمرر القناة التي يقرأها Crawl4AI، فكان يحاول تشغيل Chromium غير المثبت.
- نجح `test_crawl_live.py` على https://example.com: العنوان `Example Domain`، ومحتوى مقروء بطول 953 حرفًا في نحو 10 ثوانٍ. كما نجح طلب كامل عبر عقل X باستخدام `read_public_page`، وحُفظ المصدر والعنوان والمقتطف في سجل Deep Agents وظهرت في لوحة المتابعة.
- نجحت اختبارات Deep Agents الأربع، واختبارات الروابط/المهل الأربع، واختبار اختيار Edge. يشمل ذلك رفض الروابط الخاصة وتأكيد الإبلاغ عن انتهاء مهلة القارئ.
- تمت مراجعة نسخة التفكير العامة أولًا لكنها لم تجتز اختبار الأدوات؛ لا تعتمد. النسخة المعتمدة هي instruct، ولم تُحذف النماذج القديمة أو ملفات الرجوع. ملفات اختبارات التحقق الحالية تسجل النموذج الذي اجتاز الاختبارات.
- لا تثبت هذه الاختبارات صحة كل جواب أو قدرة على أي مهمة. حدود أربعة استدعاءات أدوات وأربع دورات نموذج للمهمة؛ والوكيل المتخصص محدود بثلاث دورات نموذج واستدعاءي أداة كحد أقصى. فشل التنفيذ يرجع خطأ ولا يدعي نجاح الفعل.
- `test_task_router.py` واختبارات توجيه العامل تختبر اختيار الحوار والبحث والعقارات والتخطيط وتعطيل الوكلاء. النماذج المتاحة محليًا كلها 3.2B–4B تقريبًا؛ اختيار Qwen هنا لأنه اجتاز اختبار الأدوات وليس لأنه أكبر نموذج ممكن.
- البحث العام يعتمد على خدمة خارجية مجانية بحصص؛ النموذج والذاكرة محليان. لا توجد مراقبة شاشة أو كتابة على حسابات الشغل أو تدريب تلقائي للأوزان.

## التحكم والرجوع

deep-reasoning.json يحدد enabled والنموذج. تغييره إلى false يعيد المحادثة لمسار Ollama السابق، بينما تبقى الذاكرة والتكاملات محفوظة. قراءة الملف تتم عند كل طلب جديد دون إعادة تشغيل ويندوز. التحقق مؤجل للنسخة النهائية حسب طلب إبراهيم.

Crawl4AI موصول كقارئ محدود للصفحات العامة فقط، وليس كمتصفح تفاعلي أو قارئ جلسات حسابات. لا يعمل Hermes أو MuseBot كخدمات داخلية؛ يظل X هو العقل الوحيد، ولا تُفعّل قنوات خارجية قبل موافقة منفصلة.
