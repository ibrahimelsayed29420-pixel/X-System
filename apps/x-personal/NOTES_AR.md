# ملاحظات التجربة

## دقة الاستماع المصري — مؤجلة بطلب إبراهيم

- المحرك: Sherpa-ONNX مع Whisper base INT8 متعدد اللغات، اللغة ar.
- الجملة المستهدفة: «يا إكس، ساعدني أرتب يومي، عندي ثلاث مكالمات واجتماع الساعة خمسة».
- النتيجة التي أرسلها إبراهيم: «نعم سعيدنا رب يومي عندي 3 مقلمايات وقتماع ساحنز».
- التقييم: دقة غير مقبولة لهذه التجربة؛ لا نعتمد النص الصوتي لتنفيذ إجراءات.
- السبب لم يُحسم: يلزم مقارنة نموذج أقوى وفحص جودة الإدخال باستخدام عينة واحدة يختار المستخدم حفظها عند العودة لهذه النقطة.
- لم يُحفظ تسجيل صوتي. تحسين النموذج وتحديد نهاية الكلام بالسكوت والتعلم من التصحيحات لم تكتمل.
- الوضع الحالي: بداية ونهاية التسجيل باستخدام Enter. مراجعة النص قبل المحادثة مستمرة.

## التالي

اختبار أمر inventory لعرض معلومات النظام والحساب الحالي بعد Windows Hello. بيانات المكتب وتجربة العقارات تظل خارج هذه الخطوة.
