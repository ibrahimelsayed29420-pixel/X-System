# عقل X المحلي — نسخة التطوير

تحديث: دخل Deep Agents إلى مسار المحادثة لاختيار الأدوات، مع نموذج Qwen instruct محلي. الشخصية الآن ثنائية اللغة وتطابق لغة المستخدم، وليس العربية فقط. تفاصيل النسخة الحالية في DEEP_AGENTS_AR.md؛ إعداد x-ibrahim القديم يبقى مسار الرجوع، بينما المحرك النشط يحدده deep-reasoning.json.

## ما يعمل الآن

- عملية خلفية لحساب Windows الحالي: `mind_service.py`. اختصارا X ووَميض موجودان في Startup للمستخدم الحالي. الخدمة تعمل الآن وحالة اللوحة المحلية `ready`؛ لم يُختبر تسجيل الخروج أو إعادة تشغيل Windows. ليست تعديلًا لنواة ويندوز ولا خدمة SYSTEM أو صلاحية مدير.
- نُقلت بيانات التشغيل والتعلّم إلى `%LOCALAPPDATA%\X-System\mind` دون حذف المصدر. نُسخت ملفات النتائج الثمانية وتطابقت بصماتها، وقاعدة التعلّم موجودة في الوجهة. لم يوجد مجلد مهارات معتمدة في المصدر، لذا لم يكن هناك ما يُنسخ منه؛ لا توجد طلبات قديمة معلّقة. ملفات النتائج القديمة ما زالت محفوظة في مكانها. قواعد الذاكرة ومخطط المهارات المنفصلة ما زالت في مساراتها الأصلية.
- شخصية «وَميض» رفيق سطح مكتب صغير ومتجهّي بلا أصول أو حزم إضافية؛ صُممت كنافذة Windows عائمة دائمًا فوق النوافذ، وتتحرك بهدوء. اختصارها يشغّل وسيطًا صامتًا بحيث لا تظهر نافذة PowerShell؛ تبقى نافذة وَميض فقط ظاهرة. عيناها وحالتها تتبعان العملية المحلية الفعلية؛ الزر يوقظ عقل X أو يطلب نومه بعد إكمال العمل الحالي، والزر الآخر يفتح لوحة التعلّم. إغلاق الشخصية وحده لا يوقف عقل X.
- الرفيق يقرأ ملف حالة X المحلي فقط كل ثانيتين، ولا يقرأ محتوى الشاشة ولا يسجل لوحة المفاتيح ولا يستمع للميكروفون. وضع السكون في Windows يوقف تحديث الرسوم مع توقف جلسة المستخدم؛ بعد الاستيقاظ يعود التحديث. هذا ليس مراقبة شاملة للجهاز أو تنفيذًا تلقائيًا لأي مهمة.
- المقصود بالتكامل الحالي هو وكيل Windows لحساب المستخدم، لا تعديل النواة أو مراقبة الجهاز كله. خدمات Windows لا تتفاعل مباشرة مع سطح المكتب؛ أي وصول لاحق إلى واجهة تطبيقات المستخدم يحتاج وكيلًا داخل الجلسة وواجهات Windows الموثقة، مع تحديد التطبيق والمصدر والتحكم في الإذن. لا يوجد الآن وسيط إداري أو صلاحية SYSTEM دائمة.
- لا توجد نافذة محادثة كبيرة؛ شخصية وَميض المصغرة تعرض الحالة وتتحكم بإيقاظ العقل أو طلب نومه، أما المحادثة فتتم عبر X.cmd chat --text، وكل طلب يمر إلى عملية الخلفية عبر طابور ملفات محلي.
- Ollama يحتفظ بنموذج x-ibrahim:latest مشتق إعدادًا من llama3.2:latest الموجود، مع personality.json وسياق العمل المهني. لم تدرب أوزان النموذج؛ إعداد الشخصية لا يضمن دقة اللغة أو الاستدلال. ظهر خلط بين اسم المستخدم والمساعد في اختبار؛ أضيف رد هوية محدد برمجيًا واختبر، بينما المحادثات الأخرى تبقى توليدية وقابلة للخطأ.
- الرد العادي يفضّل Google Gemini API (`gemini-flash-latest`) إذا توفر مفتاح Gemini في Windows Credential Manager، وإلا يستخدم Ollama المحلي تلقائيًا. أخطاء الشبكة وHTTP 408/429/5xx العابرة تعيد المحاولة ثلاث مرات بتأخير أُسّي عشوائي، ثم تعيد الرد إلى Ollama مع توضيح سبب الرجوع ضمن بيانات route. لا يُحفظ المفتاح في ملفات المشروع: شغّل `Configure-Gemini-Key.cmd` وأدخل مفتاحًا جديدًا؛ الإدخال مخفي ومخزن لحساب Windows الحالي. يرسل مسار Gemini نص الطلب والسياق المرفق (الشخصية والحقائق المحفوظة والتاريخ ونتائج البحث) إلى Google؛ لا تُفعّل الفوترة ولا تضع المفتاح في الكود أو Git. الحصة المجانية تخضع لحدود وسياسات Google وقد تتغير.
- LangGraph ينفذ الاسترجاع ← تحديد نوع الطلب ← بحث عام عند طلبه صراحة ← رد محلي ← حفظ المحادثة.
- الذاكرة الأساسية SQLite: سجل محادثة حسب الجلسة، وآخر 8 رسائل في سياق الرد، وآخر 20 حقيقة محفوظة في الاسترجاع الحالي. بيانات profile-private.json لا تدخل النموذج.
- Mem0 OSS 2.2.1 من الالتزام 26cdefb46600c0fa5953c4b5ee5003c125539fc4 تحت Apache-2.0، وQdrant local، وBGE-M3 على Ollama. الشبكة في عامل الذاكرة مقيدة برمجيًا إلى loopback، وtelemetry معطل قبل الاستيراد. اختبر استرجاع عربي فعلي. النموذج BGE-M3 تحت MIT بحسب بطاقة المصدر. لا Mem0 Cloud ولا مفاتيح استدلال مدفوعة.
- Mem0 يفهرس الحقائق التي حفظها المستخدم، دون استخلاص آلي غير مراقب من كل التطبيقات أو كلام النموذج. infer=False يتجنب تحويل تخمينات النموذج إلى ذكريات. الحذف يزيل الحقيقة من الاسترجاع الأساسي؛ الفهرس الدلالي يتزامن في الاسترجاع التالي. سجلات المحادثة والتشخيص ليست ممسوحة بذلك.
- خريطة مهارات SQLite فيها قدرات وعلاقات صريحة، و«اتعلم …» يحفظ خبرة ويربطها بمهارات حسب كلمات مرتبطة. نجاح البحث يمكن أن يسجل مسارًا إجرائيًا قابلًا لإعادة الاستخدام. هذا تنظيم للخبرة، وليس وعيًا أو تدريبًا ذاتيًا أو تثبيت كود جديد من الإنترنت تلقائيًا.
- التعلّم الإضافي يسجل نوع طلب X وأسماء أدواته المسموحة عند النجاح فقط، بلا نص المحادثة؛ ويمكن إيقافه من اللوحة، ما يمسح سجله ومسوداته المعلّقة. يمكن اختيار مجلد مواد محدد يدويًا، وقراءة ملفات Markdown أو النص فقط بعد تأكيد الإذن؛ تُستبعد الملفات المخفية وأسماء الملفات الحساسة والروابط، وتُنقّح أنماط الأسرار والبريد وأرقام الهاتف قبل التلخيص المحلي. كل مهارة مقترحة تحتاج مراجعة واعتمادًا صريحًا، ويمكن رفضها أو حذفها وسحب مصدرها من اللوحة.
- المهارات المعتمدة فقط تُمرر إلى Deep Agents تحت `/skills/project/`. ملفات المهارات تعليمات إرشادية لا تمنح أدوات أو صلاحيات إضافية؛ قائمة الأدوات المسموحة وحدود التنفيذ تبقى هي الحاكمة.
- التحقق عبر Windows Hello معطل الآن صراحة في identity-policy.json بطلب إبراهيم. ربط حساب Windows القديم محفوظ؛ التحقق يعود للنسخة النهائية عند إعادة verification_required إلى true واختبار كل مسار.

## العرض الحقيقي

افتح http://127.0.0.1:18764/؛ اللوحة تعمل محليًا وتستعلم كل ثانية من `/api/state` في عملية الخلفية نفسها، بلا بيانات تجريبية أو تقدم وهمي. لا يوجد اختصار سطح مكتب لها. مصدر المرحلة `events.jsonl` و`stage.json`، ومصدر المهارات `skills.sqlite`، وحالة العملية PID فعلي. بعد قراءة صفحة عامة، تعرض اللوحة العنوان والرابط ومقتطفًا من محتواها ضمن سجل المهمة. الحركة تظهر فقط مع مرحلة منفذة حاليًا، وعند التوقف تظهر حالة انتظار أو انقطاع الاتصال. الصفحة للقراءة فقط ولا تنفذ أوامر. الوصول محلي مع فحص Host وOrigin، بلا CORS للجهات الأخرى.

لتحسين سرعة المحادثة على الجهاز المحلي، تستخدم الردود الآن سياقًا افتراضيًا 4096 رمزًا وحدًا أقصى 128 رمزًا، وتطلب إجابة مباشرة قصيرة ما لم يطلب إبراهيم تفاصيل. يبقى نموذج Ollama محمّلًا حتى 10 دقائق بعد الطلب، ومهلة استجابة النموذج 240 ثانية لتجاوز بطء التحميل البارد. هذا يستخدم نحو 1.9 GB إضافية من الذاكرة مؤقتًا؛ يفرغ النموذج نفسه بعد الخمول.

إذا ظهر خطأ JSON يبدأ بـ`Unexpected token '<'` عند إرسال رسالة، فغالبًا صفحة الدردشة أحدث من معالج HTTP المحمّل في عملية الخلفية. من نافذة وَميض اطلب نوم X، انتظر حتى يتوقف، ثم أيقظه وافتح الصفحة مجددًا أو حدّثها بـF5. أعد الإرسال بعد التحديث؛ لا تحذف ملفات الطابور أو النتائج.

## الاستخدام

```powershell
.\X.cmd chat --text --mute
.\X.cmd mind-status
.\X.cmd mind-start
.\X.cmd mind-stop
```

أمثلة داخل المحادثة:

- «احفظ أفضل متابعة العملاء بعد الساعة خمسة»
- «اقرأ https://example.com/ ولخّص محتوى الصفحة» — قراءة صفحة عامة محليًا عبر Crawl4AI، مع عرض رابطها ومقتطفها في لوحة المتابعة. تُرفض الروابط المحلية والخاصة وروابط الجلسات.
- «ذاكرتك» ثم «انس 3» لحذف حقيقة محددة من الاسترجاع.
- «اتعلم كل مهارة جديدة ترتبط بالمهارات المكملة لها»
- «مهاراتك»
- «ابحث عن أخبار سوق عقارات عجمان» — الاستعلام يرسل إلى خدمة البحث الخارجية، والنتائج تدخل النموذج المحلي كبيانات مع روابطها. لا يوجد إرسال أو نشر أو وصول متحقق إلى حسابات العمل.

## النطاق والحدود

التعلم يشمل طلبات X، حقائق إبراهيم المحفوظة، نتائج الأدوات وتصحيحات صريحة. لا تصوير شاشة أو مراقبة لوحة مفاتيح أو ميكروفون خلفي أو متابعة حسابات أو استخراج كلمات مرور. توسيع التعلم إلى نشاط خارج X يتطلب اختيار مصادر النشاط المقصودة وتحديد ما يسجل.

العملية لا تفتح تطبيقات أو تشغل أوامر يختارها النموذج، ولا تعدّل ويندوز أو تنزل مهارات تلقائيًا. تعلم الخبرات وإضافة قدرة تنفيذية شيئان منفصلان؛ القدرة الجديدة تتطلب مصدرًا وترخيصًا ونسخة واختبارًا.

الملفات والذكريات محلية وغير مشفرة بواسطة X. بيانات التشغيل والتعلّم تحت `%LOCALAPPDATA%\X-System\mind`، وقواعد الذاكرة ومخطط المهارات القديمة تحت `D:\X-System\data\mind`، والمصادر والبيئات تحت `D:\X-System\runtime`. البحث قد يعتمد على خدمات مجانية بحصص؛ Gemini يرسل محتوى سياق الرد إلى Google عند تكوين المفتاح، بينما Ollama يبقى مسار الرجوع المحلي. الحصص المجانية ليست بلا حدود. صوت حسن اختياري وبطيء في الاختبارات السابقة.

مسار التثبيت لحساب المستخدم الحالي هو `Install-X-Mind.cmd`؛ يستخدم تجاوز سياسة PowerShell لهذه العملية وحدها، ولا يغيّر ExecutionPolicy المحفوظة، وينشئ اختصارات Startup للمستخدم الحالي دون صلاحية مدير. التثبيت والترحيل نجحا بعد إتاحة مسارات بيانات المستخدم وStartup. لا يُنشأ اختصار على سطح المكتب لأن الكتابة إليه غير متاحة في بيئة التطوير؛ استخدم الرابط المحلي أعلاه للوحة. لا تستخدم صلاحية مدير أو تغيّر ACL كحل بديل.

## التحقق

الاختبارات المركزة للتشغيل والترحيل والتعلّم ومكوّنات العقل: 13 اختبارًا ناجحًا، وفحص صياغة Python ناجح. اللوحة المحلية أعادت HTTP 200 وحالة `ready` مع عملية حية، وتعرض 8 نتائج بعد الترحيل. تطابقت بصمات ملفات النتائج المنقولة مع المصدر، وبقي المصدر دون حذف. اختبار Mem0 محلي فعلي استرجع المعلومة العربية، واختبار عملية الخلفية أعاد ردًا عبر الطابور. صفحة المتابعة اختبرت أثناء توليد رد فعلي: مرحلة respond مضيئة، مصدر بيانات حقيقي، بلا تجاوز عرض الشاشة. لم يُختبر تسجيل دخول جديد أو إعادة تشغيل Windows، كما أن ظهور نافذة وَميض يحتاج تحققًا بصريًا. هذه ليست شهادة بجودة كل رد أو نجاح تكامل كل الحسابات.
